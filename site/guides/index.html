how do i get my files?

every service on this page lets you download your own data. you ask for it, they email you a link, and you drop the file into attic. it stays on your computer.

request your data now. some exports take days or even weeks to arrive, so ask today and it will be ready when you want it.

spotify

where
spotify.com/account/privacy
how long
spotify says up to 30 days. the smaller account data often comes in about 5 days. the extended history can take longer.
the file
a zip such as my_spotify_data.zip. inside is a folder of files named like Streaming_History_Audio_2024-2026_0.json. drop the whole zip.
  1. sign in to your spotify account on the web and open privacy settings.
  2. under download your data, tick extended streaming history. you can tick account data too.
  3. press request data, then confirm the request from the email spotify sends you.
  4. when the next email arrives, download the zip. the link stops working after a while, so save the file.
  • account data on its own holds about a year of plays, with less detail. attic reads it, but the extended history tells a fuller story.
  • podcasts are kept apart from music.

netflix

where
netflix.com/account/getmyinfo
how long
up to 30 days, often sooner.
the file
a zip such as netflix-report.zip. inside is CONTENT_INTERACTION/ViewingActivity.csv. drop the zip or just that file.
  1. sign in on the web as the account owner and open the page to download your personal information.
  2. press submit request, then confirm it from the email netflix sends.
  3. when the next email arrives, download the zip.
  • the viewing activity page has a quicker download, NetflixViewingHistory.csv. it holds titles and dates but no times or lengths, so attic needs the full request instead.
  • every profile on the account is included. attic shows each one on its own.

youtube

where
takeout.google.com
how long
usually minutes to a few hours. large accounts can take a day or more.
the file
a takeout zip holding Takeout/YouTube and YouTube Music/history/watch-history.json. drop the zip. attic opens only that file, even in a big archive.
  1. open google takeout and press deselect all.
  2. scroll down to youtube and youtube music and tick it.
  3. press all youtube data included, press deselect all, then tick only history.
  4. press multiple formats and set history to json. html works too, but json is more reliable.
  5. press next step. choose to get a download link by email, export once, as a zip, then create the export.
  • watch history lists what you watched and when, not for how long, so attic counts videos, never hours.
  • if watch history was paused, those months will be missing.

chatgpt

where
chatgpt.com, settings, data controls
how long
usually minutes, sometimes a few hours.
the file
a zip holding conversations.json. drop the zip.
  1. open chatgpt, then settings, then data controls.
  2. press export data, then confirm.
  3. open the email and download the zip. the link stops working after about a day.
  • attic counts conversations, messages and words. conversation titles and your most used words are hidden in saved images unless you turn names on.

firefox

where
about:support in the address bar
how long
right away.
the file
places.sqlite. drop the copy, not the original.
  1. type about:support in the address bar and press enter.
  2. next to profile folder, press open folder.
  3. quit firefox completely. while it runs, the newest visits may sit in a side file.
  4. copy places.sqlite from that folder to your desktop or downloads folder.
  • attic reads only site names and visit times. it never reads page titles, full addresses or searches.

chrome

where
chrome://version in the address bar
how long
right away.
the file
History. drop the copy, not the original.
  1. type chrome://version in the address bar and press enter.
  2. find the profile path and open that folder in your file manager.
  3. quit chrome completely, so the file is not locked.
  4. copy the file named History, which has no extension, to your desktop or downloads folder.
  • on a mac the folder sits inside your library, which finder hides. in finder, use go to folder and paste the profile path.
  • attic reads only site names and visit times. it never reads page titles, full addresses or searches.

discord

where
discord settings, data and privacy
how long
discord says up to 30 days. it is often a few days.
the file
a zip such as package.zip, with a messages folder. drop the whole zip.
  1. open discord, then user settings, then data and privacy.
  2. press request all of my data, choose what to include, and confirm.
  3. when the email arrives, download the zip. the link stops working after a while.
  • only messages you sent are in it. attic never opens the activity folder, and never names who you sent direct messages to.
  • server and channel names are hidden in saved images unless you turn names on.

letterboxd

where
letterboxd.com/settings/data
how long
right away.
the file
a zip with diary.csv. drop the whole zip.
  1. sign in on the web and open settings, then data.
  2. press export your data.
  3. the zip downloads straight away.
  • films are counted on the day you watched them. without a diary, on the day you logged them.

goodreads

where
goodreads.com/review/import
how long
usually a few minutes.
the file
goodreads_library_export.csv. drop it.
  1. sign in on the web and open my books, then import and export.
  2. press export library.
  3. when the link appears, download the file.
  • books count when they are on your read shelf with a date read. reviews and private notes are never read.

strava

where
strava settings, my account
how long
usually a few hours.
the file
a zip with activities.csv. drop the whole zip.
  1. sign in on the web and open settings, then my account.
  2. under download or delete your account, press get started, then request your archive.
  3. when the email arrives, download the zip.
  • attic reads the type, time, distance and climb of each activity. never names, notes, routes or photos.

apple music

where
privacy.apple.com
how long
apple says up to 7 days.
the file
a zip holding Apple Music Play Activity.csv. drop the whole zip.
  1. sign in at privacy.apple.com and choose to get a copy of your data.
  2. tick apple media services information, then continue and confirm.
  3. when the email arrives, download the files.
  • ip addresses and device details in the file are never read.
  • if only the daily tracks file is there, the deck has days but no hours.

steam

where
store.steampowered.com/account/licenses
how long
right away.
the file
the saved page, such as Licenses.html. drop it.
  1. sign in on the web and open the licences and product key activations page.
  2. save the page from your browser's menu, as a web page or html only.
  • steam keeps no playtime by year, so the deck is about the games you added.

amazon

where
amazon privacy central, request your data
how long
usually a few days, up to a month.
the file
a zip with Retail.OrderHistory.1.csv inside. drop the whole zip.
  1. sign in and open request your data.
  2. choose your orders, then submit and confirm from the email.
  3. when the download is ready, download the zip.
  • attic reads dates, amounts and product names. never addresses, payment details or gift messages.
  • money is added up per currency, never converted.

attic is not affiliated with any of these services. their names are used only to say which file is which.

services change their pages from time to time. if a step here no longer matches, the file you need is usually still there under a new name.
